# Techfest 2026 – An Aetherial Renaissance

## Description

A responsive, interactive concept landing page for Techfest, IIT Bombay’s 30th edition, scheduled for 16–18 December 2026.

## Concept

An illuminated Renaissance study opens into a modern engineering field guide. Scientific line art, celestial geometry, and contemporary technical details frame the idea that yesterday’s imagination can become today’s technology.

This is a conceptual landing page created as part of the Techfest IIT Bombay College Ambassador task and is not the official Techfest website.

## Key Features

- Session-aware cinematic opening with a skip option.
- Responsive navigation, hero, and live countdown to 16 December 2026.
- Thirty abstract anniversary marks, with no invented historical milestones.
- Four interactive BUILD, THINK, DISCOVER, and EXPERIENCE pathways.
- Pointer, touch, and keyboard-friendly Aether Reveal illustration.
- Competition dossiers linked to the official Techfest competition page.
- Three-question, browser-only Aether Lab with a tailored realm recommendation.
- Custom 2D Robowars arena illustration and generational transmissions.
- Reduced-motion support, visible keyboard focus, and mobile navigation.

## Technology Stack

React, TypeScript, Vite, CSS, SVG, and Lucide React. No backend or 3D assets, Three.js, Spline, or WebGL.

## How to Run Locally

From the project root:

```bash
pnpm --filter @workspace/techfest-2026 run dev
```

## How to Build

From the project root:

```bash
pnpm --filter @workspace/techfest-2026 run build
```

Vercel can build the app at the domain root with the default base path. For GitHub Pages hosted under a repository path, set the base path during the build:

```bash
BASE_PATH=/your-repository/ pnpm --filter @workspace/techfest-2026 run build
```
